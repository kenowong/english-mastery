# English-Mastery · 中小学英语学习技巧归档

把全网各平台（知乎、B 站、官方教育号、名师专栏等）的小学 / 初中 / 高中英语学习**方法技巧**抓取、归档、分类，按「年级 + 能力维度」对应起来，配**视频**和**互动小练习**，让孩子学英语不那么枯燥。

> 排版与架构对齐 [math-mastery](https://github.com/kenowong/math-mastery)：纯前端、零依赖、数据驱动、`localStorage` 进度、可离线运行。

## 特性

- **三大学段**：小学（12 法）、初中（12 法）、高中（12 法），共 36 个技巧方法。
- **能力维度筛选**：自然拼读 / 词汇 / 听力 / 口语 / 阅读 / 写作 / 语法 / 习惯方法。
- **关键词搜索**：技巧名、方法、步骤、窍门全文检索。
- **视频集成**：每个方法带「推荐视频 / 资源」面板（默认 B 站真实检索链接，可换成具体 BV 内嵌播放器）。
- **互动小练习**（不那么枯燥）：单词闪卡翻牌、选择题即时反馈、填空核对、今日打卡清单。
- **进度与激励**：标记「已掌握」、连续打卡天数 🔥、完成率、撒花动画 🎉。
- **纯前端离线**：所有资源本地化，手机浏览器直接打开 `index.html` 即可。

## 本地运行

无需安装，浏览器直接打开 `index.html`；或起静态服务（与 math-mastery 部署一致）：

```bash
cd english-mastery
python -m http.server 8142
# 访问 http://127.0.0.1:8142/
```

NAS 部署同理：用 Python 3.12 起 `http.server` 即可（参考 math-mastery 端口 8142）。

## 数据模型（js/data.js）

每个方法是一个对象，关键字段：

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识 |
| `grade` | `primary`(小学) / `junior`(初中) / `senior`(高中) |
| `dim` | 能力维度键：phonics/vocabulary/listening/speaking/reading/writing/grammar/habit |
| `icon` | 卡片 emoji |
| `title` / `summary` | 方法名 / 一句话定位 |
| `why` | 孩子视角的趣味性说明 |
| `steps` | 核心步骤数组 |
| `tips` | 实战窍门数组 |
| `videos` | `[{title,url}]` 推荐视频/资源（默认 B 站检索链接） |
| `bv` | 可选：具体 B 站 BV 号，填了内嵌播放器 |
| `practice` | 互动练习：`{type:'flashcard'|'choice'|'fill'|'checklist', items:[...]}` |
| `source` | 来源标注 |

## 怎么加视频？

两种方式：

1. **换检索链接为具体视频**：在 `videos` 里把 `url` 改成具体 B 站视频页地址。
2. **内嵌播放器**：给方法加 `bv: "BV1xx411c7mD"` 字段，详情页会自动用 `player.bilibili.com` 内嵌。

## 🎤 跟读练习怎么用

每个方法详情页底部都有「🎤 跟读练习」区，包含 2–3 句适龄地道英文：

- **▶ 听示范**：浏览器朗读该句（顶部可选美音/英音、慢速）。
- **🎤 跟我读**：点一下后对着麦克风读，浏览器用 Web Speech 识别你说的内容，按词级匹配算相似度，给出匹配度百分比和 ⭐–⭐⭐⭐⭐⭐ 星级；≥60% 自动记一句达标，全部达标显示「🎉 跟读通关」。
- **🔴 录我的声音**：用麦克风录下自己的声音，自动生成播放器，可和示范反复对比。

> 浏览器要求：语音识别与麦克风需要 **Chrome / Edge**，且页面必须在**本机 `localhost`（如 `http://127.0.0.1:8142/`）或 https** 下打开——局域网 IP（如 `192.168.x.x`）非安全上下文时，识别/录音会被浏览器拦截。手机端同理（用 https 或本机预览）。朗读（听示范）在多数现代浏览器都可用。

跟读句子与 `window.METHODS` 解耦，集中在 `js/sentences.js`，按方法 `id` 维护，加句直接改这个文件即可。

## 离线单文件版（双击即用）

如果不想起服务器、或在手机/平板上直接打开，用 **`english-mastery-standalone.html`** 这个单文件即可——它把 CSS / 数据 / 逻辑全部内联，**双击就能在浏览器打开，零依赖、可离线**。

- 跟读练习的「听示范 / 跟我读 / 录音」在 `file://` 下（Chrome / Edge）同样可用；
- 重新构建：本目录运行 `node build_standalone.js` 即可从源码重新生成该单文件（当 `index.html` / `js/*` 有改动时）。

> 普通 `index.html` 双击也能用（同目录 `js/` 会被加载）；`standalone.html` 只是把一切打包进一个文件，方便转发和离线。

## 单词词库模块（按年级练词）

新增「🔤 单词练习」Tab（与「📚 学习技巧」并列）：先选 小学 / 初中 / 高中，再选单元开始练。每个单元三种互动：

- **🃏 闪卡**：点卡片翻面看中文释义。
- **✍️ 拼写自测**：看中文写出英文，即时核对。
- **🎤 跟读**：听示范（美音/英音、慢速）后跟读，词级匹配打分（同跟读练习的浏览器要求：localhost / https + Chrome·Edge）。
- **🔤 拼读拆解**：按「学 → 读 → 选 → 拆分 → 拼读 → 拼写」6 步拆解每个词的音节、音标与自然拼读映射——字母组合点读（**先读该音、再读例词**）、选正确音节切分、点选断点交互拆分、逐音素拼读再连读、听发音写拼写，逐步练会自然拼读。最后一步「拼写」是**听音写词**：词头只显示词义（不显示单词本身，避免直接看到答案），音节提示也需主动点开。

  **关于发音校准**：点「学」里的字母组合，会**先读该音素本身的近似读法（如 f → 「fuh」），再读一个例词**（关键词法，如 /æ/→apple、/θ/→thumb）——例词在格子里明确标注「例词」，不再被误当成音标读法（旧版点格子只读例词，等于又念了一遍整词，没教到该字母组合怎么发音）；「读 / 拼读」里的「音素拼读 / 音素慢读」为**逐音素拼读**（按 `window.PHONICS_BLEND` 的近似短音依次读出，取代旧版按音节字母碎片读导致 py 被读成 pee-eye 的问题）。拼读 token 一律写成「辅音 + 轻元音」（fuh / shuh / thuh / juh…）且必须含元音字母，否则浏览器 TTS 会把 `sh` `th` `ng` 读成**字母名**（ess-aitch / tee-aitch / en-jee）——这是已修复的历史坑，校验脚本有专项守卫。整词的标准发音以「听示范 / 听整词 / 连起来拼读」读出的真实单词为准；朗读优先选取系统英文嗓音。合成音素仅为近似示范。

数据在 `js/words.js`（`window.WORD_BANK`），按 `grade → units[] → words[{en, zh}]` 组织，前端按年级/单元加载。

**拼读拆解的音标怎么来的（诚实声明）**：引擎在 `js/phonics.js`（`window.phonicsFor(word)`）。约 155 个高频基础词（含大量不规则词、哑音字母、特殊重音）是**人工逐词校对**的，界面标「✓ 已校对」；其余单词由内置**规则引擎**按自然拼读规则推导（开闭音节、magic-e、常见字母组合等），界面标「≈ 规则推导」，仅供参考、可能出错，不作为权威音标。英语不规则词多，规则推导仅近似——真要以词典 / 教材音标为准，并把校对好的词条补进 `window.PHONICS`。规则引擎现有覆盖约 180 词，逐词校验脚本见 `tools/check_phonics.js`（已跑通：人工词条 0 错误；全词库 334 词的音素拼读 token 覆盖与「反字母名」守卫见 `tools/test_phonics_render.js`）。

**当前是核心种子词（重要）**：基于《义务教育 / 高中英语课程标准》分级框架整理的高置信度基础 / 核心词——小学 7 单元、初中 7 单元、高中 5 单元，约 350 词，用于打通练习链路。**它不是完整的 6000+ 课标 / 教材词表**，文件头已注明。

**补全为全量词表**：把新课标课标词表 + 人教版 / 外研社单元词表整理成 `{en, zh}` 数组，按册 / 单元挂到 `WORD_BANK[grade].units` 下即可，前端代码无需改动；若有官方词表电子文件（xlsx / txt / csv），交给助手转成此结构合并，保证 100% 准确。
